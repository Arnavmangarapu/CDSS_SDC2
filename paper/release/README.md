# Research review bundle

This is a locally prepared review candidate. It has not been published, does not change repository visibility and is not a substitute for a verified public archive URL.

The bundle includes evaluation source, bounded developer-authored safety fixtures, non-content selection metadata, protocols, tests and permissible aggregate results. `REVIEW_MANIFEST.json` records file hashes and the source checkout. Raw examination questions, source books, source-page snapshots, private model/extraction outputs, credentials, database backups, Git history and author-contact manuscript files are excluded.

The new live safety pilot is development evidence on reused synthetic cases. It is not clinical validation. The base paper's values are externally reported results, not a reproduced baseline. The separate historical QA experiment remains incomplete.

Read the included `evaluation/INDEPENDENT_EVALUATION_PROTOCOL.md` and `evaluation/safety_live_pilot.protocol.json`. The production source loader requires local publisher snapshots and ontologies/models acquired under applicable terms; they are not bundled. The frozen run's source hashes identify what was used, but do not grant permission to redistribute those inputs. The bundle is not presented as a fully self-contained reproduction without those dependencies.
